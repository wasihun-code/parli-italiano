# Progression Rules

This document outlines the mandatory progression flow for Learning System V3.

## The Cognitive Curve
All learning items (Vocabulary, Phrases, Sentences) MUST follow this strict sequence:
`Recognition → Recall → Production → Conversation`

## Definitions & Allowed Transitions

### 1. Recognition
- **Allowed Exercises:** Listen, Listen & Choose, Match.
- **Rule:** An item MUST complete at least two successful Recognition exercises before it is eligible for Recall.
- **Transitions:** If failed, remains in Recognition. If passed, moves to Recall.

### 2. Recall
- **Allowed Exercises:** Build Sentence, Recall (Fill-in-the-blank).
- **Rule:** An item MUST complete at least one successful Recall exercise before it is eligible for Production.
- **Transitions:** If failed repeatedly, drops back to Recognition. If passed, moves to Production.

### 3. Production
- **Allowed Exercises:** Dictation, Speaking, Spelling.
- **Rule:** Production exercises represent high cognitive load and MUST NOT be presented until the item has cleared Recognition and Recall.
- **Transitions:** If failed, drops back to Recall. If passed, item achieves "Learned" status and is ready for Conversation.

### 4. Conversation
- **Allowed Exercises:** Scripted Branching Dialogue.
- **Rule:** The final validation of the scenario. Relies on the vocabulary and structures taught in the preceding phases.
- **Transitions:** Success grants implicit Global Mastery credit. Failure requires reviewing the specific failed concepts.

## Hard Constraints
- Production exercises may **never** appear before recognition exercises.
- A user cannot face a "Spelling" challenge for a word they have never seen in a "Flashcard" or "Match" context.
