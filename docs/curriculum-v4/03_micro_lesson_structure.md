## Micro‑Lesson Curriculum (Full Sequence)

All 80 conversation turns are broken into **micro‑lessons** following strict dependency order. Each micro‑lesson respects:

- **1–3 turns**
- **≤ 8 new words**
- **≤ 5 new phrases**
- **≤ 3 new sentences**

Words are introduced **before** the phrases that need them. Phrases before sentences. Sentences before turns.

---

### Legend
- **W** = new word(s)
- **P** = new phrase(s)
- **S** = new sentence(s)
- **T** = new conversation turn(s)
- Sentence IDs refer to the 80 sentences defined in the earlier sentence registry.
- Turn IDs correspond to the original order (t_001 … t_080).
