# Phase 9.7a: Sentence Pedagogical Strategy

## 1. The Goal
Sentences must not just "appear" in the session; they must be actively broken down and reconstructed by the learner to build fluency.

## 2. Implementation
By combining the Phase 9.7 weight updates (`Listen -> Match -> Spelling`) with the Phase 9.7a distribution guarantees, sentences now undergo the following lifecycle:
1. **Sentence Listening:** Learner hears the full spoken sentence and must select the matching text, forcing audio comprehension without reading.
2. **Sentence Understanding:** Learner is presented with an English translation and must select the correct Italian sentence.
3. **Sentence Production:** Learner must type or assemble the sentence from memory.

## 3. Result
This pipeline eliminates the possibility of passive memorization.
