# Phase 7.6 — User Journey Test

## 1. Fresh User Journey
**Path:** Apartment Key Pickup -> Hotel Check-In
- **Vocabulary Lesson:** The user learns `chiave`, `grazie`, `sì`. These words transition to `LEARNED` state (Interval: 1 day).
- **Conversation (Apt Key):** The user achieves a Perfect Conversation. 
- **Reinforcement:** `chiave`, `grazie`, `sì` receive a 2.0x implicit review credit. Their intervals are pushed from 1 day to 3 days immediately.
- **Result:** The user bypasses the next day's Daily Review for these words naturally.

## 2. Intermediate User Journey
**Path:** Hotel Check-In
- **Adaptation:** The user skips the flashcards for `grazie` because they are `LEARNED`.
- **Conversation (Hotel):** The user makes 2 minor mistakes during the dialogue.
- **Reinforcement:** `grazie` receives a 75% credit ("GOOD"). Its interval is extended normally. The new word `prenotazione` (learned earlier in this scenario) also receives credit.
- **Result:** Flashcard fatigue remains eliminated, but the memory trace for `grazie` is safely reinforced in context.

## 3. Advanced User Journey
**Path:** Hostel Dorm
- **Initial State:** The user knows 400 words. `grazie` is in `MASTERED` state (Interval: 45 days).
- **Adaptation:** The lesson is 95% skipped.
- **Conversation (Hostel):** The user completes the conversation perfectly.
- **Reinforcement:** `grazie` is reinforced in context. The `due_at` timer is pushed out another 90 days. 
- **Result:** The user maintains their A1/A2 vocabulary permanently just by playing conversations, rarely needing to open the Daily Review queue for basic words.
